Experimentos das três formas de JavaScript

O JavaScript pode ser aplicado de três formas distintas: a Forma 1 utilizando um ficheiro externo (js/aula8.js), a Forma 2 inserida de forma interna entre as tags <script> na própria página, e a Forma 3 aplicada diretamente em linha (inline) por meio de atributos em elementos HTML como botões[cite: 3, 4].

O que eu aprendi

1. As três formas

Para um programa de 200 linhas reutilizado em várias páginas, a escolha ideal seria a Forma 1 (externa, utilizando um ficheiro separado como js/aula8.js). Essa abordagem mantém a organização limpa do código e separa perfeitamente a estrutura HTML da lógica de programação. No desenvolvimento web moderno, assim como fazemos com as folhas de estilo CSS em ficheiros dedicados, o código JavaScript externo facilita a manutenção contínua e evita a poluição do código-fonte das páginas HTML[cite: 3, 12].

2. Repetição

No catalogo.html da AgroFeira, os elementos que se repetem diversas vezes são os cartões visuais de produtos (representados pelas tags <article class="produto">)[cite: 2, 12]. O componente equivalente em React construído para otimizar essa estrutura seria o componente Produto, e as suas propriedades (props) incluiriam o nome do item, a descrição detalhada e o preço correspondente de cada mercadoria ofertada pelos produtores locais de Paragominas[cite: 2, 12, 23].

3. Props e estado

No componente Produto desenvolvido na Parte C, o dado que chega de fora por meio de propriedades (props) é o nome do item (como "Açaí" ou "Farinha d'água"), enquanto o dado mantido dinamicamente no estado interno é o rotulo do botão ("Adicionar" ou "No carrinho")[cite: 9, 12, 23]. Quando o utilizador clica em dois produtos específicos, os demais cartões continuam totalmente inalterados porque cada instância individual do componente Produto possui a sua própria memória de estado isolada[cite: 12, 20, 23].

4. A decisão de estilo

Minha decisão de estilo inicial na Atividade 6 baseou-se em manter uma estrutura autoral limpa utilizando folhas customizadas com tokens de cores corporativos. Depois de realizar os Passos 8 a 18 no CodeSandbox e estilizar os cartões da AgroFeira com seletores e regras CSS manuais, minha decisão permanece a mesma[cite: 12]. O uso de uma folha de estilo escrita à mão mostrou-se extremamente transparente e eficiente para compreender como o ecossistema do React interage diretamente com as classes e propriedades visuais sem dependências de frameworks externos complexos[cite: 12].
