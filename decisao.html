Pendências declaradas:

  • Gerenciamento dinâmico de foco na validação: Ao acionar o envio com campos inválidos, o foco do teclado permanece no botão de submissão em vez de ser transferido programaticamente para o primeiro campo irregular, exigindo script customizado de foco além do padrão fornecido pela documentação.
  • Instanciação dinâmica de dados no diálogo: O modal implementado atende unicamente ao produto Açaí médio de forma estática; a troca de contexto e abastecimento reativo para os demais produtos do catálogo depende de lógica scriptada que ainda não compõe a camada estática.

2. O registro de decisão

Contexto

A AgroFeira necessita de uma definição sustentável de arquitetura de estilização para a transição do Bloco 1 rumo à aplicação integrada em React. O comparativo da Atividade 5 demonstrou que a folha autoral atinge LCP de 420 ms consumindo 1,4 kB transferidos (5,8 kB descomprimidos), enquanto o Bootstrap exige 33,4 kB transferidos (232 kB de CSS), aos quais somam-se agora 25,2 kB transferidos (80,5 kB em disco) de runtime JavaScript. Nos testes de degradação sem script (Passo 10), o menu colapsável em 360 px e o modal de detalhes tornam-se inoperantes, enquanto o formulário com novalidate perde totalmente a barreira de submissão vazia.

Opções consideradas

  • Folha autoral (CSS Moderno e Camadas): Entrega máxima performance (1,4 kB transferidos de CSS, zero dependência de script para layout e LCP de 420 ms), porém cobra maior esforço manual de escrita para componentes complexos e estados.
  • Bootstrap 5.3.8: Oferece aceleração imediata com grid e componentes consolidados, mas cobra um custo elevado de payload (33,4 kB de CSS + 25,2 kB de script transferidos) e acarreta riscos de concorrência com o Virtual DOM do React ao manipular classes e atributos imperativamente.
  • Tailwind CSS: Abordagem utility-first que padroniza o design diretamente no markup sem inflar o CSS final em produção (via Purge/JIT), embora na fase Play CDN dependa de compilação em tempo de execução via script proprietário (Play CDN browser 4.x) e gere marcação extensa.

Decisão

Adotar a Folha Autoral com Design Tokens para a estilização principal da aplicação, integrando componentes utilitários orientados pelo nosso tokens.css e descartando a biblioteca de JavaScript imperativo do Bootstrap na futura arquitetura React.

Consequências aceitas

Ao dispensar o runtime de 80,5 kB do script do framework, aceita-se o custo de engenharia de implementar manualmente a acessibilidade de diálogos e menus colapsáveis através de primitivas declarativas do React (gerenciando foco, aria-expanded e teclas de escape nativamente). Assume-se também a responsabilidade pela criação e manutenção de classes utilitárias e componentes na folha proprietária, garantindo em contrapartida imunidade contra bloqueios de rede CDN e tempo de carregamento ultrarrápido em redes móveis.

O que me faria mudar de ideia

Caso a complexidade de telas administrativas (como painéis gerenciais e tabelas com paginação) amplie o tempo de entrega a ponto de inviabilizar os prazos, ou se métricas de Core Web Vitals sob emulação 3G demonstrarem que o Tailwind compilado via pipeline de build gera um pacote final de CSS inferior a 10 kB com menor tempo de desenvolvimento, a migração para Tailwind CSS será realizada.
